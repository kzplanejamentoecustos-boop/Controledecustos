📖 Tutorial — Como importar o JSON

PASSO 1 Selecionar o arquivo JSON
  • Abra o arquivo HTML da ferramenta de Controle de Custos de Obra.
  • No bloco “1. Importar dados da obra (JSON)”, clique em “Importar base de dados”.
  • Escolha a base de dados da obra no seu computador para carregá-la.
PASSO 2 Acessar a aba Visualizador
  • Com o JSON já carregado (confirmação em verde na tela), vá até “2. Como você vai acessar?”.
  • Clique em “Visualizador (somente leitura)” para consultar os dados da obra.
  • Use “Engenheiro de Custos (edição completa)” caso precise editar os dados.
